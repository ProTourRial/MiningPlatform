Universal Miner Detection

Hardware universal.Data tetap jujur.

Worker dapat berasal dari ASIC, GPU, CPU, FPGA, rig hybrid, atau perangkat lain. MiningPlatform menggabungkan signature Stratum, deklarasi user, monitoring agent, dan miner API tanpa menganggap tebakan sebagai fakta.

Supported hardware model

Tidak dikunci ke ASIC.

Jenis perangkat dan algoritma adalah dua hal berbeda. Semua kategori hardware dapat dicatat dan dimonitor, sedangkan share hanya diterima bila miner mendukung algoritma pool yang aktif.

High confidence
ASIC

Firmware, hashboard, fan, power, temperature, dan Stratum signature.

Agent verified
GPU

NVIDIA, AMD, Intel, jumlah device, memory, clock, utilization, dan software miner.

Agent verified
CPU

Arsitektur, core/thread, operating system, software miner, dan reported hashrate.

Evidence based
FPGA / HYBRID

Perangkat campuran disimpan sebagai hybrid, bukan dipaksa menjadi klasifikasi yang salah.

Batas alpha: validator aktif tetap BTC/SHA-256. CPU, GPU, atau FPGA dapat terhubung bila software dan hardwarenya mendukung SHA-256 Stratum V1. Algoritma lain membutuhkan adapter terpisah.
Detection flow

Sumber dan confidence ikut disimpan.

1. SubscribeUser-agent diterima melalui Stratum.
2. DetectSignature dicocokkan tanpa overclaim.
3. CorroborateAgent, API, dan deklarasi user memperkuat bukti.
4. PersistProfile, possible types, evidence, dan capability dicatat.
5. MonitorTelemetry per device disimpan terpisah.
