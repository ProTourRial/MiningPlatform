# ADR-0012: Exact Referral Fee Accounting

**Status:** Accepted
**Date:** 2026-08-21
**Authority:** `PROJECT_VISION.md`

## Context

MiningPlatform charges a standard 0.50% platform fee. A miner may add a valid referral code to the Stratum worker username, for example `account.worker#MP05`, to receive an immediate program rate of 0.375%. The referral beneficiary earns 0.125% of gross mining rewards generated by attributed miners. Integer basis points cannot represent 0.375% exactly.

## Decision

1. Parts-per-million are authoritative for financial arithmetic: standard fee 5,000 PPM, referred fee 3,750 PPM, and commission 1,250 PPM.
2. The 1,250 PPM commission is funded from the 3,750 PPM charged fee. It is not an additional miner deduction. The platform therefore retains 2,500 PPM for a referred allocation.
3. Every allocation freezes the effective fee PPM, referral program version, code/beneficiary snapshot, commission amount, and retained-platform amount.
4. The accounting identity is:

   `gross = provider costs + user net + charged platform fee`

   `charged platform fee = referral commission + retained platform revenue`

5. Referral attribution is created only after successful worker-credential authentication and is immutable per mining account. Unknown, inactive, self-owned, or conflicting codes fail closed.
6. Attribution added after a period has already received contribution facts does not retroactively change that period. The referral rate becomes fully effective when all facts in the settled period occurred after attribution.
7. `MP05` is the default site-donation code. Its commission is posted to a system donation liability. A real destination and payout remain disabled until separately verified and approved.
8. Each user receives one stable personal referral code. Code ownership and program economics are immutable; economic changes require a new program version.

## Consequences

- Historical allocations remain reproducible without looking up mutable current rates.
- Referral commission never causes an unbalanced journal or a hidden additional charge.
- A mid-period code change cannot rewrite already accepted work.
- PPM is authoritative; basis points remain a human-readable decimal representation and may contain `37.5`.
- Referral payout and donation payout are liabilities only until the wallet/payout production gates are complete.
