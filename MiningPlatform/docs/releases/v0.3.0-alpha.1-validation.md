# Validation Report — v0.3.0-alpha.1

Date: 2026-08-03

## Executed in the packaging environment

- Source and release structure inspection.
- Static release checker.
- Release-manifest checksum verification.
- JavaScript syntax checks for release scripts.
- Standalone Node tests: 9 security tests, 3 upstream configuration/parser tests, 3 supported-event regression tests, and 5 production authenticator tests (20/20 total).
- Docker Compose YAML parse where a YAML parser is available.

## Not executable in the packaging environment

The environment did not have pnpm cached and had no network access to the npm registry. Therefore `pnpm install`, Prisma client generation, TypeScript monorepo typecheck, unit tests requiring workspace dependencies, Next.js build, NestJS build, and Docker-backed PostgreSQL/Redis integration were not executed here.

These remain mandatory release gates on a normal Node 22 + pnpm 10.13.1 environment:

```bash
pnpm install --frozen-lockfile
pnpm db:generate
pnpm typecheck
pnpm test
pnpm build
```
