# MiningPlatform v0.3.0-alpha.1 — Control Plane Foundation

Release date: 2026-08-03  
Compatible upgrade source: v0.2.0-alpha.6  
Schema version: 7

## Implemented

- Account registration with a default BTC mining account.
- Email verification token lifecycle and outbox request event.
- Password login, account lock, short-lived access token, rotating refresh session, logout, and session revocation.
- Password-reset token lifecycle with revocation of existing sessions.
- TOTP setup, enable, disable, encrypted secret storage, and one-time recovery-code login and consumption.
- RBAC roles `USER`, `ADMIN`, and `OWNER`; administrator endpoints require TOTP, and an audited operator CLI bootstraps privileged roles.
- User profile and active-session management.
- Scoped API key creation, listing, use, and revocation.
- Worker CRUD, one-time worker credential output, credential rotation/revocation, and audit trail.
- Production dashboard REST snapshot and authenticated WebSocket rooms.
- Notification inbox and encrypted notification-channel registry.
- Docker production environment wiring for Control Plane secrets, multi-upstream configuration, reconnect settings, bounded share queue, job cache, and VarDiff.
- Release manifest generation and static release verification for this version.

## Corrected defects

- A website-created worker can now obtain a `WorkerCredential` accepted by `ProductionWorkerAuthenticator`.
- The production dashboard no longer depends on `ENABLE_DEVELOPMENT_DASHBOARD`.
- The realtime Redis consumer can run in production.
- Docker Compose no longer forces the legacy single TCP upstream path and now passes alpha.6 resilience settings.
- `workerDeviceDetected` remains registered and projected by the mining worker.
- Full-release packaging excludes `.git` and regenerates the payload manifest.

## Explicitly not production-complete

- Email and external notification delivery adapters.
- Distributed rate limiting, managed DDoS protection, IP reputation, and public certificate automation.
- Reward settlement, contribution accounting, automatic ledger posting, balance projection, wallet orchestration, and payouts.
- Hardware firmware/configuration control and predictive analytics.
- Multi-algorithm or multi-coin plugin runtime.
- Docker-backed migration, load, stress, and chaos test evidence in this build environment.
