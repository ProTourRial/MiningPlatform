# MiningPlatform v0.3.0 Direct-Overwrite Validation

Author: Abia Nugrahanto

## Purpose

This packaging revision allows the clean v0.3.0 source tree to be overlaid onto an existing large development directory without deleting `node_modules`, `.env`, databases, backups, uploads, or user-local progress files.

## Corrected packaging defects

- Restored the missing `scripts/apply-delete-manifest.mjs` utility.
- Made PowerShell and shell scripts resolve the project root from their own location.
- Replaced whole-directory checksum assumptions with managed-source verification.
- Added optional cleanup limited to generated build/cache directories.

## Overlay regression scenario

The recovery package was applied over a v0.2.0-alpha.3 source tree containing representative additional paths:

- `node_modules/fake-package/`
- `apps/web/.next/cache/`
- `apps/api/dist/`
- `custom-progress/notes.txt`

Results:

- All 410 managed source files matched the v0.3.0 source manifest.
- Extra files did not cause verification failure.
- Default verification preserved all extra paths.
- Optional generated-artifact cleanup removed `.next` and `dist` only.
- `node_modules` and the custom progress file remained intact.
- v0.3.0 static structure checks passed.

This validates source overlay behavior only. Dependency-aware typecheck, Prisma generation, database migration, and production build remain target-environment checks.
