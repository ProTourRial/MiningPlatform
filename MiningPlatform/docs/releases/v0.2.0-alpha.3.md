# MiningPlatform v0.2.0-alpha.3

Release name: **Local Upstream Gateway Pipeline**

## Delivered

- Upstream Stratum V1 TCP/TLS client.
- Local upstream simulator.
- Upstream response correlator with timeout handling.
- Upstream session finite state machine.
- Initial connection retry with exponential backoff.
- Difficulty and extranonce relay.
- Job normalization and multi-job registry.
- `clean_jobs` invalidation.
- Local validation before upstream submission.
- Separate pending, accepted, and rejected upstream events.
- Reference fixture with expected Bitcoin header and hash.
- End-to-end TCP test from downstream miner through gateway to simulator.

## Safety status

```text

```

## Remaining blockers

- Provider-specific captured fixtures.
- Production worker authentication.
- Transparent reconnect or failover after an active upstream disconnect.
- PostgreSQL and Redis integration tests.
- Multi-replica duplicate and session tests.
- Load and soak tests.
