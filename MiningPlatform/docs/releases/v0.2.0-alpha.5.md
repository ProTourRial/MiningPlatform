# MiningPlatform v0.2.0-alpha.5

Release name: Architecture and Miner Identity  
Date: 2026-07-31  
Owner: Abia Nugrahanto

## Scope

Rilis ini merapikan arsitektur domain dan mengganti batas autentikasi worker development dengan foundation autentikasi miner produksi. Rilis tidak menambahkan reward, wallet, payout, atau multi-upstream failover.

## Implemented

- Control, Mining, Accounting, Event, Monitoring, dan Operations Plane.
- Bounded contexts dan context map resmi.
- Data-flow dan event-flow diagrams.
- Domain event catalog dan versioning policy.
- ADR canonical 0001–0007 tanpa nomor duplikat.
- `WorkerCredential` model dan migration.
- scrypt secret hashing dengan format versioned.
- create, rotate, dan revoke credential melalui CLI.
- PostgreSQL credential lookup.
- Redis authentication rate limit.
- persisted failed-attempt dan credential lock state.
- generic miner-facing authentication errors.
- success/failure audit logs.
- production runtime guard untuk auth driver.
- `workerDeviceDetected` projection bug fix.

## Runtime modes

```text
Development:
STRATUM_DEV_MODE=true
STRATUM_AUTH_DRIVER=development

Production foundation:
STRATUM_DEV_MODE=false
STRATUM_AUTH_DRIVER=postgres
EVENT_STORE_DRIVER=postgres
EVENT_BUS_DRIVER=redis
```

## Credential lifecycle

```text
create
  -> ACTIVE
  -> rotate: old REVOKED + new ACTIVE
  -> revoke: REVOKED
  -> optional expiry: rejected after expiresAt
  -> repeated failures: lockedUntil
```

## Security boundary

- secret plaintext hanya ditampilkan sekali;
- database menyimpan scrypt hash;
- raw IP tidak disimpan;
- password tidak masuk log atau event;
- unknown worker dan wrong secret menghasilkan respons miner yang sama;
- development authenticator ditolak di production.

## Release verification gate

Rilis harus diverifikasi dari folder hasil ekstraksi, bukan dengan menjalankan tool langsung di dalam ZIP.

```bash
pnpm install --frozen-lockfile
pnpm db:generate
pnpm typecheck
pnpm test
pnpm build
```

Shortcut:

```bash
pnpm verify:alpha5
```

Migrasi harus diuji pada database kosong dan salinan database alpha.4. Prosedur lengkap tersedia di `docs/releases/v0.2.0-alpha.5-upgrade.md`.

Paket incremental menyertakan `DELETE_FILES.txt`, `apply-patch.sh`, dan `apply-patch.ps1` agar ADR duplikat dari alpha.4 tidak tertinggal.

## Release metadata and diagnostics

Every Node service binary supports machine-readable version output:

```bash
pnpm --filter @mining/stratum-server start -- --version
pnpm --filter @mining/mining-worker start -- --version
```

The API exposes:

```text
GET /version
```

The response includes `version`, `commit`, `buildDate`, `schemaVersion`, `migration`, and `component`.

Worker credential inventory:

```bash
pnpm worker:credential list demo.worker1
```

The release payload is described by `release-manifest.json`. Its `patchChecksum` covers the sorted patch payload and intentionally excludes `release-manifest.json` itself and detached `.sha256` files, avoiding checksum self-reference.
