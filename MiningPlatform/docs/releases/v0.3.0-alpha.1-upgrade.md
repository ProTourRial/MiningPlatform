# Upgrade v0.2.0-alpha.6 -> v0.3.0-alpha.1

## 1. Backup

Create a PostgreSQL backup and retain the v0.2.0-alpha.6 application package. Do not apply this migration to the only copy of a production database.

## 2. Required secrets

Add the following values to `.env` before starting the API:

```dotenv
AUTH_JWT_SECRET=<at-least-32-random-bytes>
AUTH_ENCRYPTION_KEY=<32-byte-base64url>
AUTH_IP_HASH_KEY=<at-least-32-random-characters>
AUTH_TOKEN_ISSUER=mining-platform
AUTH_TOKEN_AUDIENCE=mining-platform-control-plane
AUTH_ACCESS_TOKEN_SECONDS=900
AUTH_REFRESH_TOKEN_DAYS=30
AUTH_SECURE_COOKIES=true
ENABLE_REALTIME_GATEWAY=true
```

Keep `AUTH_SECURE_COOKIES=true` behind HTTPS. Set it to `false` only for isolated local HTTP validation.

Generate the encryption key with:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

## 3. Upstream configuration

Production Compose defaults to `UPSTREAM_DRIVER=multi`. Set `UPSTREAM_POOLS_JSON` to a non-empty JSON array. The service now fails closed when multi mode has no pool list. For one upstream, set `UPSTREAM_DRIVER=tcp` and provide `UPSTREAM_HOST`, `UPSTREAM_USERNAME`, and `UPSTREAM_PASSWORD`.

## 4. Migration

```bash
pnpm install --frozen-lockfile
pnpm db:generate
pnpm db:migrate:deploy
pnpm --filter @mining/database exec prisma migrate status
```

The required migration is `20260803010000_control_plane_foundation`. It backfills missing `UserSecurity` and `UserProfile` rows for users created before this release. Legacy password values that were not generated by the website password hasher still require an operator-assisted reset.

## 5. Validation

```bash
pnpm verify:v030-alpha1:static
pnpm verify:v030-alpha1
```

Disposable database validation:

```bash
MIGRATION_TEST_ACK=v030-alpha1-fresh-empty-database pnpm verify:migration:v030-alpha1:fresh
MIGRATION_TEST_ACK=alpha6-upgrade-copy pnpm verify:migration:v030-alpha1:upgrade
```

## 6. First administrative account

Registration creates a `USER`. Promote a verified active account through the audited operator CLI, then enable TOTP before using `/api/v1/admin/*`:

```bash
pnpm user:role set owner@example.com OWNER --confirm=owner@example.com:OWNER
```

Do not expose an unauthenticated role-promotion endpoint.

## 7. Rollback

Application rollback is possible only before relying on the new Control Plane tables. Database rollback requires restoring the pre-upgrade backup; destructive down migrations are intentionally not supplied.
