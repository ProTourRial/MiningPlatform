# Comparison: audited GitHub main vs uploaded v0.3.0-alpha.1

GitHub baseline: commit `014f6845da41e6b709fa1948a106c40ed07a92d0`, previously audited from branch `main`.
Uploaded baseline: `MiningPlatform-v0.3.0-alpha.1.zip` supplied on 2026-08-03.

A live re-fetch of GitHub was not available in the packaging environment. This comparison therefore uses the exact previously audited commit snapshot and the uploaded archive contents.

| Area | Audited GitHub baseline | Uploaded alpha.1 | alpha.2 result |
|---|---|---|---|
| Workflow location | Under `MiningPlatform/.github/workflows`, not discoverable by GitHub | `.github/workflows` at the uploaded project root | Packaged at repository-root `.github/workflows`, with source commands under `MiningPlatform` |
| Frozen dependency install | CI used a non-frozen install in the audit | CI already used `--frozen-lockfile` | Retained in root CI and enforced in all Dockerfiles |
| PostgreSQL/Redis CI services | Missing/incomplete in audited workflow | Present in uploaded CI | Retained; separate quality, fresh migration, and upgrade migration jobs |
| Fresh/upgrade migration proof | Not established | Alpha.1 migration scripts existed | Alpha.2 fresh and alpha.1→alpha.2 upgrade jobs added |
| Refresh rotation | Current-token hash only; concurrent rotation risk | Same basic session model | Atomic token record rotation, persistent family history, replay-family revocation, parallel test |
| Worker deletion | Previously identified as non-atomic | Already transactional in alpha.1 | Retained and extended to credential revocation/logout/password reset |
| Duplicate worker rename | Not safely mapped | Precheck absent | Precheck plus `P2002` conflict mapping |
| TTL validation | Previously unbounded numeric parsing | Already bounded in alpha.1 | Retained and regression-tested |
| API-key request authentication | Previously reported incomplete | Already implemented in alpha.1 guard | Retained; no duplicate implementation added |
| Production email | Not available | Outbox events existed but no provider delivery | Resend identity-email adapter added through outbox |
| Observability | Baseline metrics/alerts existed | Prometheus/Grafana/alerts present | Refresh replay metric and critical alert added |
| Docker E2E | Not proven | Compose/Dockerfiles present | Root path-filtered Docker E2E workflow added |
| Payment receiving addresses | Not configured | Not configured | Public registry added, disabled by default, no balance credit or payout |
| Branch protection | Not enforced | Not enforceable from source | CODEOWNERS and required-check guidance added; repository setting remains external |
