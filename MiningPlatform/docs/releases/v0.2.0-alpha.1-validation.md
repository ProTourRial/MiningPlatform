## TCP Smoke Result

The test starts the development Stratum server on localhost, negotiates version rolling, subscribes, authorizes the development worker, receives a deterministic low-difficulty job, searches for a valid nonce, submits the share, and verifies session, job, and accepted-share events.

## Release Decision

The artifact remains an alpha development release. It is not approved for production miners or real funds.
