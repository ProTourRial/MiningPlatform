## Validation limitation

The available dependency directory contained a Windows Prisma schema engine while the build environment is Linux. Therefore the following commands were not represented as completed:

```bash
pnpm install --frozen-lockfile
pnpm db:generate
pnpm typecheck
pnpm test
pnpm build
```

The source-level checks above do not replace generation of an alpha.5 Prisma Client. In particular, `scripts/worker-credential-cli.ts` requires the generated client to expose `workerCredential`.

## Required release-owner checks

Run in one environment with the correct pnpm and executable Prisma engine:

```bash
pnpm verify:alpha5
```

Then verify migrations against:

1. a newly created empty PostgreSQL database;
2. a disposable database restored from alpha.4.

Instructions: `docs/releases/v0.2.0-alpha.5-upgrade.md`.
