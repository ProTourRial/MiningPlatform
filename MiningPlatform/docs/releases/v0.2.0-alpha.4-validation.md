## Universal support conclusion

The platform is no longer modelled as ASIC-only. Worker profiles support CPU, GPU, FPGA, ASIC, HYBRID, OTHER, and UNKNOWN hardware. Detection is evidence-based and stores source plus confidence.

The active share validator remains Bitcoin SHA-256. A CPU, GPU, FPGA, or ASIC miner can use the gateway only when its mining software speaks compatible Stratum V1 and supports SHA-256. Other algorithms require dedicated adapters.

## Validation limitations

- Prisma engine validation could not run because this environment cannot download the Linux Prisma schema engine.
- Full Next.js production build could not run because the uploaded dependency artifact contained a Windows SWC binary. The final archive excludes all `node_modules`; a normal `pnpm install --frozen-lockfile` on the target machine will install the correct platform binary.
- PostgreSQL, Redis, Docker, load, and soak integration remain pending.
- No production miner or real funds may be connected.
