# Laporan Implementasi MiningPlatform v0.3.0-alpha.1

Tanggal audit dan penyusunan: 3 Agustus 2026  
Basis upgrade: `v0.2.0-alpha.6`  
Nama rilis: **Control Plane Foundation**  
Schema version: **7**  
Migrasi terbaru: `20260803010000_control_plane_foundation`

## Ringkasan Eksekutif

Paket ini memperbaiki cacat packaging alpha.6, membangun fondasi Control Plane yang sebelumnya belum terhubung, dan menghubungkan pembuatan worker di website dengan `ProductionWorkerAuthenticator`. Rilis ini layak dijadikan **integration/staging candidate**, tetapi **belum layak produksi publik** karena build monorepo penuh, migrasi PostgreSQL nyata, pengujian Redis/PostgreSQL, TLS publik, delivery email/notifikasi, accounting, wallet, dan payout belum melewati release gate.

Klasifikasi hasil:

- **Selesai pada alpha ini:** autentikasi website dasar, sesi JWT/refresh, verifikasi/reset token lifecycle, TOTP dan recovery code, RBAC, profil, Worker CRUD dan kredensial, API key, dashboard produksi, admin dasar, registri kanal notifikasi terenkripsi, konfigurasi multi-upstream Compose, baseline Prometheus/Grafana/alert, CI dan packaging.
- **Sebagian:** email verification dan password reset sudah lengkap pada API/UI/token/outbox, tetapi delivery email belum diimplementasikan; notification channel sudah dapat diregistrasikan tetapi adapter pengiriman/verifikasi tujuan belum ada; rate limiting API masih in-process dan edge protection masih dasar.
- **Ditunda dengan sengaja:** reward settlement, contribution calculation produksi, ledger posting otomatis, balance projection, wallet orchestration, payout, firmware/configuration management, advanced analytics, plugin multi-coin, dan chaos/load production evidence.

## Temuan Audit Paket Alpha.6

1. Arsip awal berisi `.git`, sehingga membawa metadata repository yang tidak diperlukan pada full release.
2. `release-manifest.json` tidak sinkron: jumlah payload dalam manifest berbeda dengan isi aktual.
3. Sebagian daftar kekurangan yang diberikan sudah memiliki fondasi di alpha.6, khususnya bounded context, event catalog, pool adapter, multi-upstream manager, reconnect/circuit breaker, bounded share queue, job routing/cache, dan VarDiff foundation.
4. `workerDeviceDetected` sebenarnya sudah terdaftar pada `supportedMiningEvents` dan memiliki handler projection. Pengujian regresi tetap dipertahankan.
5. `ProductionWorkerAuthenticator` sudah ada, tetapi Control Plane belum memiliki alur website untuk menerbitkan `WorkerCredential` yang dapat dipakai miner.
6. Dashboard hanya memiliki jalur development dan Compose produksi belum meneruskan konfigurasi resilience alpha.6 secara lengkap.

## Perubahan yang Diimplementasikan

### 1. Arsitektur dan Dokumentasi

- ADR resmi dinormalisasi pada `docs/adr/README.md`; ADR-0009 mendefinisikan identity, revocable session, RBAC, TOTP, dan pemisahan kredensial miner.
- Boundary Control Plane dan request flow didokumentasikan pada `docs/architecture/control-plane-foundation.md`.
- Katalog event identity ditambahkan ke `docs/events/catalog.md`.
- Upgrade guide, release note, validation note, dan laporan implementasi disediakan di `docs/releases/`.
- Arsitektur accounting/wallet tidak diklaim selesai; boundary tersebut tetap tertutup.

### 2. Control Plane API

Implementasi utama berada di `apps/api/src/modules/`.

- Registrasi akun dan pembuatan BTC mining account default.
- Lifecycle token verifikasi email dan reset password: hash dipakai untuk verifikasi; plaintext reference dienkripsi AES-256-GCM untuk kebutuhan delivery worker.
- Password website memakai format scrypt terversi.
- Access token HMAC-SHA256 berumur pendek dan refresh token opaque yang disimpan sebagai hash.
- Refresh token dirotasi; sesi dapat dicabut melalui logout, reset password, user session management, atau suspensi admin.
- Cookie `HttpOnly`, `SameSite=Strict`, dan `Secure` pada produksi; mutasi berbasis cookie memerlukan Origin yang cocok dengan `APP_URL`.
- TOTP RFC 6238, secret terenkripsi, setup/enable/disable, dan recovery code sekali pakai.
- Role hierarchy `USER < ADMIN < OWNER`; endpoint admin memerlukan TOTP aktif.
- Profil user dan daftar/cabut sesi aktif.
- API key berscope, secret hanya ditampilkan satu kali, dan penyimpanan hanya berupa hash.
- Worker CRUD, soft delete, device declaration, credential create/rotate/revoke, dan audit trail.
- Admin overview, daftar user, suspend/activate user, serta pencabutan sesi saat suspensi.
- Registry kanal EMAIL/TELEGRAM/DISCORD/WEBHOOK dengan tujuan terenkripsi.

### 3. Website

Implementasi UI utama berada di `apps/web/src/`.

- Halaman register, login, logout, verify-email, forgot-password, dan reset-password.
- Dukungan input TOTP atau recovery code pada login.
- Profile management, active session management, TOTP setup/disable, recovery code display.
- Worker creation dan credential rotation; password miner ditampilkan satu kali.
- API key create/list/revoke; token ditampilkan satu kali.
- Notification channel registry.
- Admin user status panel.
- Production dashboard REST + Socket.IO namespace `/mining` dengan cookie session.
- API client melakukan refresh session satu kali pada respons 401 sebelum mengulang request.

### 4. Database dan Migrasi

`packages/database/prisma/schema.prisma` kini berisi **40 model** dan **28 enum**.

Model baru:

- `UserProfile`
- `AuthSession`
- `EmailVerificationToken`
- `PasswordResetToken`
- `ApiKey`
- `NotificationChannel`

Migrasi `20260803010000_control_plane_foundation`:

- menambah role `ADMIN`;
- menambah enum dan tabel Control Plane;
- menambah pending TOTP secret dan last-login metadata;
- membuat indeks serta foreign key;
- melakukan backfill `UserSecurity` dan `UserProfile` untuk user dari versi sebelumnya.

Catatan: password legacy yang bukan hasil hasher website tetap memerlukan reset/operator migration; migrasi tidak mencoba mengubah password yang tidak dapat direkonstruksi.

### 5. Mining Plane dan Upstream

- Worker yang dibuat melalui API memperoleh `WorkerCredential` scrypt yang kompatibel dengan `ProductionWorkerAuthenticator`.
- Compose produksi meneruskan `UPSTREAM_POOLS_JSON`, reconnect/backoff/jitter, recovery cycle, queue capacity/timeout, job cache, dan VarDiff.
- `UPSTREAM_DRIVER=multi` sekarang gagal tertutup bila `UPSTREAM_POOLS_JSON` kosong.
- `UPSTREAM_DRIVER=tcp` mewajibkan host, username, dan password.
- Publish address Stratum tetap loopback secara default; operator harus secara eksplisit memilih `0.0.0.0` setelah firewall/DDoS control tersedia.
- Fondasi alpha.6—pool adapter, priority/weight registry, circuit breaker, failover, provider-scoped job IDs, bounded queue, dan VarDiff—dipertahankan, bukan dibuat ulang.

### 6. Monitoring dan Operasional

- User-scoped production dashboard dan authenticated WebSocket rooms.
- Domain health endpoint untuk admin.
- Prometheus metrics diperluas untuk user, session, worker, upstream, dan outbox.
- Baseline Grafana datasource/dashboard dan Prometheus alert rules.
- CI menggunakan frozen lockfile, PostgreSQL/Redis services, migration deploy, lint, typecheck, test, build, dan manifest verification.
- Workflow tag membuat source ZIP dan SHA-256 artifact.
- Manifest generator mengabaikan `.git`, `node_modules`, `.next`, `dist`, coverage, cache, dan Prisma generated output agar checksum merepresentasikan source release.

- managed DDoS/WAF dan Stratum edge protection;
- secret manager, rotation procedure, dan key versioning;
- IP reputation/abuse detection;

## Risiko Terbuka

**Kritis untuk produksi publik**

- Tidak ada email delivery worker sehingga aktivasi/reset produksi belum dapat disampaikan otomatis.
- Accounting, wallet, dan payout belum tersedia dan tidak boleh diaktifkan.
- Belum ada bukti migrasi upgrade pada salinan database alpha.6 nyata.
- Belum ada full build/typecheck dengan dependency workspace.

**Tinggi**

- Rate limiter API masih per-instance.
- Tidak ada public TLS/DDoS deployment profile.
- Multi-upstream belum melewati provider-specific captured fixture dan soak/failover test.
- Notification delivery adapter dan verification handshake belum tersedia.

**Menengah**

- Admin console masih terbatas.
- Recovery-code consumption belum memiliki optimistic concurrency guard lintas request simultan.
- Distributed tracing dan centralized logging belum tersedia.
