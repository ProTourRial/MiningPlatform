# MiningPlatform v0.2.0-alpha.2

Nama rilis: **Core Hardening**

## Fokus

Rilis ini memperbaiki kesalahan yang ditemukan pada audit repository gabungan. Tidak ada klaim bahwa upstream pool, reward settlement, wallet, atau payout sudah selesai.

## Hasil utama

- source resolution monorepo diperbaiki melalui dependency-aware Turbo tasks;
- direct dependency dipatok ke versi exact;
- Next.js typed routes dan same-origin routing diperbaiki;
- Nginx mendukung Socket.IO upgrade;
- dashboard development dipisahkan dari production;
- PostgreSQL outbox dan outbox worker ditambahkan;
- Redis Stream memiliki pending recovery dan dead-letter flow;
- duplicate share memakai Redis reservation;
- hashrate memakai bucket 60 detik dan lima rolling window;
- state machine dan idempotency contract digunakan pada projection;
- ledger memperoleh database constraints;
- historical mining relations tidak lagi cascade delete;
- Docker service berjalan sebagai non-root dengan environment terisolasi;
- scheduler retention dipusatkan;
- login dan register diberi status pratinjau agar tidak tampak berfungsi.

## Batas rilis

Rilis ini hanya untuk development dan review arsitektur. Blocker sebelum upstream staging tercatat pada README dan manifest proyek.
