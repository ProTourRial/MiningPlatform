# MiningPlatform v0.3.0-alpha.3 — Vision Authority and Versioned Fee Policy

- Release date: 2026-08-13
Status: Alpha; no real-funds production use

## Purpose

This release establishes [`../../PROJECT_VISION.md`](../../PROJECT_VISION.md) as the highest project-documentation authority and converts the owner-approved initial platform fee of **0.5%** into a versioned, auditable policy foundation.

## Delivered

- Project Vision, Product Constitution, Production Gap Register, roadmap, and project manifest now form an explicit authority chain.
- Schema version 9 adds `MiningFeePolicy`, scope and lifecycle enums, effective windows, 0–10,000 basis-point bounds, and policy references.
- Active `platform-default` version 1 is 50 basis points (0.5%).
- Registration and public system configuration resolve the active database policy.
- The Reward Engine provides deterministic specificity-based resolution and rejects ambiguous active policies.
- Reward allocations carry policy ID, version, basis points, and an immutable JSON snapshot foundation.
- Upgrade migration preserves custom account rates and historical allocation amounts; old amounts are annotated, never recalculated.

## Safety boundary

This release does not complete durable settlement, ledger posting, reconciliation, wallet signing, conversion, or payout. `PAYOUTS_ENABLED=false` and the no-real-funds warning remain mandatory.

## Acceptance gates

- `pnpm verify:v030-alpha3:static`
- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- fresh and alpha.2 upgrade migration verification
- `pnpm build`
- release and managed-source manifest verification

The local gates are accepted and recorded in [`v0.3.0-alpha.3-validation.md`](v0.3.0-alpha.3-validation.md). Repository CI and Docker E2E remain additional release gates. Alpha.3 remains explicitly unsuitable for real-funds production use.
