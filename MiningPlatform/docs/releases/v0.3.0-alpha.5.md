# MiningPlatform v0.3.0-alpha.5 - Financial Truth Foundation

- Release date: 2026-08-16
- Owner: Abia Nugrahanto
- Status: Alpha; no real funds

## Outcome

This release establishes the first durable path from an upstream-accepted share to an imported settlement, versioned 0.5% fee allocation, balanced double-entry journal, and user balance projection.

The implementation is intentionally fail-closed. An upstream variance produces a reconciliation exception and no posting. Payouts, signing, broadcast, custody, and conversion remain disabled.

## Technical scope

- Schema version 10 and migration `20260816020000_financial_truth_foundation`.
- Immutable `ContributionFact` and `RewardPeriodContribution` records.
- Atomic-unit fields for settlement, allocation, reconciliation, and journal lines.
- Serializable accounting transactions with bounded retry and database idempotency keys.
- Deterministic largest-remainder gross/cost allocation.
- Versioned fee resolution and immutable snapshot per allocation; default remains 50 bps.
- Per-user liability accounts and balances projected only from posted/reversed journal lines.
- Equal-and-opposite reversals with original-entry retention.
- Transactional outbox events for contribution, settlement, journals, and reward-period closure.
- Authenticated user reward, trace, ledger, and balance APIs.
- OWNER+TOTP operator CLIs for settlement import and journal reversal.

## Deferred gates

- Reconciliation exception approval/resolution workflow.
- Selected real-provider settlement and protocol evidence.
- Multi-replica Redis/PostgreSQL recovery and partition tests for the accounting event path.
- Production load, soak, chaos, observability ownership, and incident drills.
- Every wallet, signer, payout, conversion, and controlled-funds capability.
