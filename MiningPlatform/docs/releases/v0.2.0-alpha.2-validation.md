# Validation Report v0.2.0-alpha.2

Tanggal: 30 Juli 2026

## Pemeriksaan yang lulus

- Repository berisi 241 file tanpa `node_modules`, `.next`, `dist`, atau credential produksi.

- ZIP sumber berhasil diekstrak tanpa path traversal dan nested repository.
- TypeScript dan TSX syntax parsing: 118 file.
- JSON parsing: 50 file.
- YAML parsing: 5 file.
- Prisma schema structural scan: 31 model dan 21 enum.
- Migration structural scan dan foreign-key target verification.
- Secret-pattern scan untuk private key, seed phrase, dan credential nyata.
- Runtime test terisolasi: 22 test lulus.

Test runtime mencakup:

- Bitcoin genesis header hash;
- compact difficulty target;
- accepted development share;
- duplicate share;
- stale job;
- hashrate calculation;
- Stratum configure, authorize, submit, dan notification codec;
- idempotency acquisition dan conflict;
- finite state transitions;
- double-entry application invariant;
- FOLLOW_UPSTREAM allocation preservation;
- rejection untuk negative contribution dan duplicate account.

## Pemeriksaan yang belum dapat dijalankan

Lingkungan pembuatan arsip tidak memiliki akses npm registry dan Docker daemon. Pemeriksaan berikut harus dijalankan setelah `pnpm install` pada mesin development:

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
docker compose -f docker-compose.yml -f docker-compose.dev.yml config
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build
```

Integration test PostgreSQL, Redis, outbox recovery, dan consumer dead-letter juga masih harus ditambahkan sebelum upstream staging.

## Kesimpulan

Repository layak dipakai sebagai baseline pengembangan `alpha.2`. Repository belum layak untuk ASIC produksi, upstream pool staging, wallet nyata, atau dana nyata.
