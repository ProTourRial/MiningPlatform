# v0.3.0 Packaging Hotfix r1

Author: Abia Nugrahanto

This packaging revision corrects the incremental installer distributed with the initial MiningPlatform v0.3.0 Identity & Access artifacts.

- Added the missing `scripts/apply-delete-manifest.mjs` file required by `apply-patch.ps1` and `apply-patch.sh`.

- Added explicit preflight checks for Node.js and required patch files.
- Added clearer Windows execution instructions and process-scoped execution-policy guidance.

The application version and database schema remain `0.3.0` and schema version `7`. This is a packaging-only revision.
