# MiningPlatform v0.3.0-alpha.4 - Distributed Upstream Health

- Release date: 2026-08-15
Status: Alpha; no real-funds production use

## Purpose

This release closes the in-process-only upstream health gap. Gateway replicas coordinate provider circuit state and half-open recovery probes through Redis while retaining a local fail-open safeguard if coordination becomes unavailable.

## Delivered

- A provider-neutral `DistributedPoolHealthCoordinator` contract and deterministic in-memory implementation.
- Atomic Redis failure accounting, circuit opening, recovery, and one cross-replica half-open probe lease.
- Redis server time as the lease authority, preventing host clock skew from changing provider eligibility.
- Multi-upstream manager integration that skips globally open providers and retains local circuit behavior during coordinator faults.
- Production configuration guards, bounded state TTLs, redacted health snapshots, and startup resource cleanup.
- ADR-0010, which keeps connections session-scoped until provider-safe shared multiplexing invariants are implemented and proven.
- Cross-client Redis integration coverage and a production operations runbook.

The platform fee baseline remains **0.5% (50 basis points)** under the alpha.3 versioned policy. Schema version 9 and migration `20260813010000_versioned_fee_policy` are unchanged.

## Safety boundary

This release does not prove compatibility with a selected real upstream provider. Provider fixtures, extension/version negotiation, controlled failover, regional routing, production VarDiff, safe multiplexing implementation, load, soak, and chaos evidence remain pending. Reward settlement, ledger posting, reconciliation, wallet signing, conversion, and payouts also remain disabled.
