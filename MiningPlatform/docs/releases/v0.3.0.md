# MiningPlatform v0.3.0

Release Name: **Identity & Access**  
Author: Abia Nugrahanto  
Date: 2026-07-31

## Added

- Registration, login, logout, JWT access tokens, refresh rotation, and authoritative web sessions.
- Email verification, forgot/reset/change password.
- TOTP two-factor authentication and one-time backup codes.
- Session inventory with device, browser, location hint, activity, per-device revoke, and revoke-all.
- Permission-based RBAC with USER and OWNER roles.
- User profile and settings endpoints.
- Worker CRUD, ownership, status, statistics, and universal hardware declaration.
- Worker credential create, rotate, revoke, expire, last-used, and created-by metadata.
- API key lifecycle management.
- User audit log API and dashboard page.
- Production dashboard summary for worker state, hashrate, upstream pools, PostgreSQL, Redis, API health, and recent events.
- Authentication rate limiting with Redis production storage and development memory fallback.
- Schema version 7 migration and machine-readable release manifest.

## Security

- Web passwords and miner credentials remain separate.
- Refresh and account tokens are stored only as hashes.
- TOTP secrets are encrypted; backup codes are hashed.
- JWT validity is checked against authoritative session state.
- Password change/reset revokes active sessions.
- Refresh-token reuse revokes the affected session.
- Raw IP addresses are not stored.
