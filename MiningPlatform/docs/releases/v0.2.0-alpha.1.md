# v0.2.0-alpha.1

Release name: Core Mining Pipeline Alpha

Tanggal: 30 Juli 2026

## Tujuan

Rilis ini membangun jalur pengembangan yang dapat diuji dari koneksi Stratum sampai pembaruan dashboard. Rilis ini belum boleh digunakan untuk miner atau dana produksi.

## Alur yang Tersedia

```text
Stratum test miner
    ↓
mining.subscribe
    ↓
mining.authorize
    ↓
local development mining.notify
    ↓
mining.submit
    ↓
Bitcoin SHA-256d header validation
    ↓
duplicate, stale, format, time, and difficulty checks
    ↓
Redis Stream domain event
    ↓
PostgreSQL mining projection
    ↓
5-minute worker hashrate snapshot
    ↓
hashrate.updated event
    ↓
NestJS WebSocket gateway
    ↓
Next.js development dashboard
```

## Implementasi

- Parser Stratum V1 untuk `mining.configure`, `mining.subscribe`, `mining.authorize`, dan `mining.submit`.
- Session state untuk connected, subscribed, authorized, active, dan disconnected.
- Development worker authentication yang hanya aktif melalui `STRATUM_DEV_MODE=true`.
- Development mining job dengan difficulty rendah untuk smoke test.
- Rekonstruksi coinbase, merkle root, dan 80-byte Bitcoin block header.
- Double SHA-256 dan perbandingan target share.
- Network target decoding dari compact bits.
- Duplicate fingerprint berdasarkan worker, job, extranonce2, ntime, nonce, dan version bits.
- Stale job, malformed field, invalid time, unauthorized worker, dan low difficulty rejection.
- Redis Stream publisher dan consumer group.
- Idempotent PostgreSQL projection untuk miner session, job, share, dan hashrate snapshot.
- WebSocket event untuk worker online, worker offline, accepted share, rejected share, dan hashrate.
- Stratum smoke client yang mencari nonce valid dan mengirim share.

## Batas Keamanan

- Mode development ditolak ketika `NODE_ENV=production`.
- Kredensial development berasal dari environment dan tidak digunakan sebagai autentikasi produksi.
- Seluruh event tetap ditulis ke file JSONL development sebagai jejak lokal.
- Endpoint snapshot development tidak tersedia ketika `NODE_ENV=production`.
- Payout tetap dinonaktifkan.
- Wallet RPC tetap tidak diimplementasikan.

## Belum Selesai

- Version rolling saat ini memakai mask statis. Integrasi mask dari upstream belum tersedia.
- Koneksi dan failover ke upstream pool nyata.
- Relay `mining.set_difficulty`, `mining.set_extranonce`, dan `mining.notify` dari upstream.
- Submission share ke upstream dan penyimpanan hasil upstream.
- Transactional outbox antara fakta database dan event.
- Pending entry recovery, retry policy, dan dead-letter stream Redis.
- Hashrate window 1 menit, 15 menit, 1 jam, dan 24 jam.
- Integration test PostgreSQL dan Redis.
- Automated end-to-end test yang menyalakan seluruh container.
- Load test dan latency benchmark.
- Authentication dan authorization dashboard user.

## Keputusan Rilis

Versi ini adalah alpha. Definition of Done v0.2.0 belum terpenuhi sampai seluruh item kritis di bagian belum selesai ditutup.

## Hasil Validasi

- Unit test mining core: 5 lulus.
- Unit test Stratum protocol: 4 lulus.
- TCP smoke test nyata: `mining.configure` sampai `mining.submit` lulus.
- Share development diterima dan event session, job, serta local accepted share ditulis ke JSONL.
- TypeScript syntax scan, JSON validation, dan YAML validation lulus.

Validasi ini memakai event bus memory dan development event store. Jalur Redis, PostgreSQL, dan container penuh belum diuji pada lingkungan ini. Prisma CLI juga belum tersedia, sehingga migration wajib divalidasi dengan `prisma validate` dan database staging sebelum dipakai.
