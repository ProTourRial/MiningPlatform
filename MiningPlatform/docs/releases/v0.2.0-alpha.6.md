# MiningPlatform v0.2.0-alpha.6

Release name: **Upstream Resilience**  
Date: 2026-07-31  
Owner: Abia Nugrahanto

## Added

- Pool adapter abstraction for Stratum V1 providers.
- Multi-upstream registry using priority and weight.
- Automatic recovery, exponential backoff, jitter, circuit breaker, and backup selection.
- Transparent downstream session continuity during local failover tests.
- Provider-scoped multi-job registry and lifecycle invalidation.
- Bounded share queue with concurrency, timeout, and backpressure.
- Upstream pool selection, failover, health, and worker difficulty events.
- Conservative VarDiff foundation with upstream difficulty floor.
- Database migration for upstream resilience state and pool health metadata.
- TCP failover regression test from downstream miner to backup simulator.

## Changed

- A live upstream disconnect no longer immediately closes the downstream miner while recovery is possible.
- Share submission is routed through the provider that owns the job.
- Job projection stores provider key and original upstream job ID.
- Release metadata now reports schema version 6 and migration `20260731110000_upstream_resilience`.

## Safety status

This release is for protocol development and internal review. It is not approved for production ASIC fleets or real-fund accounting.

## Known gaps

- Captured fixture from the selected production upstream provider.
- Shared upstream multiplexing across miners.
- Distributed circuit state across gateway replicas.
- PostgreSQL, Redis, Docker, load, soak, and chaos verification.
- Control-plane management UI for upstream pools.
- Production VarDiff policy and long-running statistical validation.
